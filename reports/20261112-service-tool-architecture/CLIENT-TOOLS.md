## Select one useful adaptation after the call

Match: the main constraint → the simplest useful module → available inputs → client environment → observable acceptance check → manageable support/cost. Prefer an existing reusable component that the client can actually operate. A prompt/template pack, editable document/Sheet, structured file or bounded configuration may be enough. An MCP/API/agent connector is offered only when the specific interface, permissions, license, cost and test are verified.

Handoff includes purpose, inputs, a worked example with permitted data, expected output, short use instructions, limits, owner, export/retention and support boundary. Client acceptance means they can complete the intended task in their environment; a file or credential-free configuration alone does not prove integration.

Implementation order: evidence/buyer brief → writing/profile workflow → selected visual/review tools → qualified research and email/campaign support → ads only for an agreed need.
