# Tool selection by function — lean first version

Selection means a recommended role and fallback, not an account already connected. Keep the client's current workable stack where possible. Costs and access are checked per client and before a purchase or launch.

| Function | First choice | Agency/client responsibilities and readiness |
|---|---|---|
| Intake, source notes and review | Shared document and Sheet/board; existing writing skills. | Agency organizes and edits; client supplies facts, voice and reviewer. Existing methods; new client sharing/access not set. |
| Founder profile and publishing | Native LinkedIn profile/Page and manual native preview. | Client owns account; operator/permissions agreed. No posting or research-read API access inferred. |
| Visual production | Current owned design system, editable SVG/layout workflow; Figma when authorized. | Agency creates/reviews; client checks facts/brand. Existing publication assets do not prove a client generator app. |
| Company discovery | Public company sites and native research; optional Monid company search/enrichment. | Agency verifies domain/role/criteria; client approves ICP. Dated Monid inspection exists; no data endpoint tested. |
| Business email data | Optional Hunter finder/verifier. | Agency reviews source/identity; client agrees recipient rules and payer. Vendor API/MCP documented; no Hunter account/connector tested here. |
| Sending | Existing client-owned authenticated mailbox; Google Workspace Starter if a new mailbox is justified. | Client owns domain/DNS/mailbox; authorized operator and opt-out/stop process. Authentication/setup not performed here. |
| Sequences and replies | CRM/Sheet first; Hunter connected-mailbox sequence when scope justifies it. | Separate finding/verification from actual sending. Test a controlled fixture and reply/stop behaviour before live operation. |
| Paid LinkedIn | Campaign Manager; public Ad Library for examples; Insight Tag/conversion path if in scope. | Client supplies roles, budget and landing/privacy approvals; agency scopes setup/reporting. No account, API or tracking connection verified. |
| Analytics, booking and billing | Native analytics/CRM records; client-owned booking/invoice tools. | Website tasks87–91 govern our site measurement. Per-client baseline, operator, payer and exports remain explicit. |

## Dated cost observations, 12 November 2026

- **Hunter:** Free lists 50 credits/month and one connected mailbox. Starter displays $34/month equivalent with **$408 billed yearly**; this is not a verified month-to-month quote. [Official pricing](https://hunter.io/pricing).
- **Workspace Starter:** standard USD $8.40/user/month flexible or $7/user/month with annual commitment; region/tax may differ. Reuse an existing mailbox before adding a seat. [Official billing comparison](https://knowledge.workspace.google.com/admin/billing/compare-flexible-and-annual-fixed-term-payment-plans).
- **Monid:** prior connected inspection lists Context.dev fast $0.004/page; akta identity resolution $0/call; enrichment is section-priced. No paid execution. Reinspect exact terms/rates before use. [Dated inspection](../20261112-decision-guide-tools/monid-catalog.json).
- **LinkedIn ads:** official guidance lists a $10 daily minimum; it is not a useful test-budget recommendation or a cost-per-lead forecast. Agree media spend separately from fees. [Budget guidance](https://business.linkedin.com/advertise/ads/best-practices/maximize-your-budget).

Use SPF, DKIM and DMARC with the chosen domain/mailbox; verify actual configuration and sending policy. Google publishes different requirements for general and bulk senders. Authentication is not proof of inbox placement. [Sender guidelines](https://support.google.com/mail/answer/81126?hl=en).

Native research, drafts and an authorized send are separate steps. LinkedIn restricts scraping and unauthorized automated account activity; do not promise a bot that bypasses that boundary or the project's collector hold. [LinkedIn guidance](https://www.linkedin.com/help/linkedin/answer/a1341387/prohibited-software-and-extensions).

The full matrix specifies every service function, required/optional/excluded use, inputs/outputs, operator/payer, API readiness, cost and fallback. Vendor marketing does not establish a competitor's private setup or our live integration. A cheap per-request price excludes review, setup and support time.

For OutSpoken itself, the board already records company-email setup. Verify the actual provider, DNS and sender operation before outreach; do not buy a duplicate mailbox merely to follow this example stack.
