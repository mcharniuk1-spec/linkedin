## First build/rehearsal shortlist

1. **T00 Evidence kit** — prerequisite for trustworthy outputs and reusable client onboarding.
2. **T03 Decision-to-post workbench** — clearest core Voice deliverable; build hooks from the supported point and make the body fulfil them. The review’s actual-company rehearsal is a useful manual baseline.
3. **T02 Profile studio** — tangible profile work, gated on verified role, evidence and voice samples.
4. **T05 Profile/landing review** — adds source/claim checking and prioritized edits; keep observations, inference and recommendations separate.
5. **T01 Buyer/message brief, then T06 Search planner** — T01 supports qualification and outreach preparation; T06 is a later Pipeline utility for locating/searching, not an outreach sender. Keep ICP hypotheses distinct from verified need or buying interest.

Start with T00–T03 per the source’s next-action plan; treat T05/T06 as later modules. The recommendations above identify what to prioritize, not product readiness.
