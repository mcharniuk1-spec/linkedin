## Rebuild the visuals

Use an existing Python3 and macOS Swift/AppKit/CoreText installation; no dependency installation is performed. From this folder run `python3 build_visuals.py`, then `swift render.swift .`. The portable renderer uses the included licensed fonts. PNG/PDF rendering is macOS-specific; captions, SVGs and HTML remain portable. The copy is the frozen source; rebuilding visuals does not rewrite captions.
