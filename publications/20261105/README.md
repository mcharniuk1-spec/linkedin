# Ten Outspoken carousel drafts — 5 November 2026

[Open the gallery](assets/index.html) after serving the repository locally, or download [all ten carousels](assets/outspoken-10-carousels.zip). Each publication includes five separate 1080 × 1350 PNG slides, a five-page PDF and a caption. The slide manifest includes alt-text drafts and hashes. `content.json` holds editable source copy; `render.py` regenerates into `generated/` using the existing project font and identity assets and Pillow. Drafts require founder review before publication.

The graphics use the owner-selected R13 stencil lockup, Fraunces, Mona Sans and Geist Mono, and the navy/marigold/pearl palette. They are original editorial layouts, not photographs or copied competitor images. The R13 identity selection is recorded; final artistic acceptance remains open.

The ninth carousel explains the dataset: a reaction is the combined count of available reaction types (including Like); comments and reposts are separate. The selected 279-post sample has different observed denominators and does not measure reach or conversion. See [the detailed interpretation](../../reports/20261105/README.md).

Regenerate from the repository root with `python3 publications/20261105/render.py`; it writes separate review outputs and does not overwrite this delivered package. Pillow must already be installed. Inspect the rendered slides before sharing. No post was published by this package.
