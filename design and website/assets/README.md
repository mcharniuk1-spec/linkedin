# Asset projection

`public/` preserves browser URL paths. Files here were selected from the explicit asset allowlist and copied only after exact source bytes matched one recorded SHA-256 identity. The release manifest records every copied file and all expected omissions.

Excluded rights holds include the owner-supplied study/symbol crops and derived reference beauty, a V3 interview lineage gap and an unresolved V4 generated-sculpture source record. A prior public deployment is not treated as a new redistribution-rights receipt. Keep these materials in their existing local source store.
