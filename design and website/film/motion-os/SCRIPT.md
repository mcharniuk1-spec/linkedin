# Outspoken OS motion film: scene-by-scene script (proposed)

28.00 s, 4:5 1080x1350, 30 fps. Calm, precise, one focal element at a time; every scene ends on the same slash seam. Captions repeat the narration for muted autoplay.

**Plot.** Build the identity in front of the viewer: two letters become a mark, the mark becomes a system, the system carries one promise, the promise ends in one action.
