# Outspoken V3 silent style proofs

Three original18-second H.264 films,30fps,with no audio. Six composition families are recomposed for landscape960×540,square720×720 and portrait540×960: title; interview/caption; source-review boundary; evidence/source context; publication; closing CTA.

`scenes.html` is the editable native-text scene source. Query `?aspect=landscape&scene=1` through `scene=6`; use `square` or `portrait` for the other layouts. Source masters remain in the exact manifests listed by `manifest.json`. The film uses current navy-Out/silver-spoken V3 identity, original curved plates, actual V3 evidence object, generated human shadow and original publication artwork. It contains no V2 logo, external footage, recorded customer, fabricated result or audio.

Movement is deliberately restrained:200ms fades and1.4% slow pose zoom. This is a silent style study,not parity with the interactive website camera,button shader or shared-layout media transition. Interview/workflow/publication frames are visibly illustrative. The closing CTA is a design specimen; it does not book a call.

The manifest records all source hashes,18 rendered scene proofs,each MP4’s SHA256/dimensions/frame count/duration/size and full decoder result. Run-local QA also stores a decoded midpoint for every scene. Original frame/source lettering stays editable in HTML; the MP4 is opaque,not an alpha object or a live interface.
