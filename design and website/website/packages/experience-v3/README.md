# Outspoken experiential primitives — V3

Import from `packages/experience-v3/index.ts`. Both exports import the namespaced CSS themselves. No new dependency is required.

`ThreeTiltButton` keeps `ActionButton`'s native button props, `variant` and `loading`. Additional `tone="navy|marigold|silver"` and `arrow` affect the treatment. It renders original rounded, beveled Three.js geometry with directional and rim lights. One lazily created offscreen WebGL renderer paints a decorative 2D canvas per visible button. This avoids one WebGL context per button. Pointer position changes actual mesh rotation; the DOM hit target stays fixed. The spring stops at rest. Intersection and resize observers bound work. Geometry/material/context are disposed when no visible buttons remain. WebGL failure retains a solid accessible DOM fallback. Reduced motion keeps the mesh still, while focus and activation retain lighting feedback.

`PerspectiveVideo` accepts `poster`, `src`, `title`; optional `description`, `caption`, `className`, `onOpenChange`, `tilt="left|right"` and `autoPlayOnOpen`. The optional autoplay is muted; the default requires the user's play action. The closed plate downloads no video. Activating it mounts a native modal dialog and the video. Escape, the Close button and outside click restore the triggering button and page scroll. Motion shares the plate's layout into the central view. Use `onOpenChange` to dim or move only nearby background copy, and reset it on close. Never hide or disable the dialog's DOM ancestor. Native dialog inert behavior contains focus. Place the trigger outside sticky/transformed parents if a browser's shared-layout interpolation becomes visually distorted.

Two perspective directions and all three button tones have stories. The film URL is supplied by the application; the story's old V2 style study is a functional fixture, not approved V3 art direction. Source type is Archivo/Inter from the canonical brand license.


## Founder constellation / real 3D brain

`NeuronField({imageSrc, progress?, staticOnly?, modelSrc?})` is the full-width viewport scene. `progress` is a MotionValue; scroll updates never call React state. The default source is `/assets/revisions/v3/neural/human-reference-brain.glb`, the real HRA/Allen reference model supplied by the integrator. Its 283 region geometries are transformed into world space, centered using Box3, uniformly scaled, and merged into one render mesh. Original smooth normals are retained. The source is CC BY 4.0: the application must retain the asset's `provenance.json` attribution and license credit. Materials, lighting, stars, camera movement and labels are original Outspoken treatment. No medical model, localization, cognition or outcome claim is made by the five founder-content labels.

The model loads only within 80 px of the viewport. Surface/interior stars use actual reference-mesh positions: 14,000 desktop / 7,600 phone. DPR is capped at 1.5. Camera orbit moves from roughly 70 degrees to frontal over progress 0–.2; a subtle twist settles by .22. The five native labels reveal around .14–.24 and use actual geometry points with projected SVG leaders. Progress .65–1 recedes and fades the complete mesh and stars. The root owns the controlled flash, publication and service-word transition. When no progress is supplied the scene defaults to the pinned .3 state. Reduced motion/staticOnly keep all labels and geometry visible. The frame loop pauses offscreen and settles 1.2 seconds after input. Resources and listeners are disposed on unmount. WebGL/network failures retain the supplied artwork or original artistic geometry fallback; they do not claim real-model readiness.

`data-model-load`, `data-geometry`, `data-meshes`, `data-draw-meshes`, `data-points`, `data-camera`, `data-view-projection` and `data-cloud-matrix` expose finite verification values. Each label has exact `data-anchor-world` and `data-projected` coordinates. These are verification data, not content labels.
