# OUTSPOKEN Brand Studio V5

`BrandStudio` is the integrated Objects & Media gallery. Import from `index.ts`. CSS is scoped to `os5-*`; this package does not edit the application or the shared experience package.

```tsx
<BrandStudio
  wordmarkSrc="/assets/revisions/v5/identity/selected/lockup-gradient.svg"
  videoSrc="/video/revisions/v5/Outspoken-v5-style-proof-landscape.mp4"
/>
```

The manifest enumerates 210 button variants: seven palette colors × primary/secondary × five edge styles × front/left/right. The default gallery presents 14 color/type pairs; the accessible style/pose filters expose all combinations. A shared offscreen Three.js renderer paints the decorative button surfaces. Native buttons and live text remain the hit targets. Static presentation poses use CSS3D; reduced motion disables pointer rotation. The component does not book or send anything.

MediaFrame provides 24 image/video combinations: four frame treatments × three poses × two media types. `object-fit: contain` preserves the full source composition. Captions remain upright and outside the image. Five people directions combine three new V5 fictional portraits with two retained fictional interview/editorial sources.

Nineteen editable specimens cover three banners, four editorial blocks, two semantic schemas, two routed annotations, two native publication shells with separate artwork, two fictional email examples, one fictional feedback example, and three caption treatments. Props configure the components; the text-editing toggle makes demonstrated slots editable in place. Gallery edits are local, do not persist and do not publish content.

The 108 object images are actual front/left/right renders from 25 retained semantic GLBs and 11 retained extruded word sculptures. The source model and render hashes, camera normalization and material/light recipe are in `../assets/revisions/v5/objects/manifest.json`. Original V3 GLBs remain unchanged. A transparent PNG is a static view; use the original archived GLB for a real turn. Essential labels stay native text. Silver/marigold word sculptures use a darker presentation ground for readability.

The identity section distinguishes the selected supplied reference crop, exact vector masters, eight unchanged study crops, and actual GLB views. `identity-views.json` activates model/wordmark view paths only after the maker freeze. Neither an import inventory nor a source count proves Figma mutation or owner acceptance.

All people, posts, feedback and emails are visibly fictional. Keep these disclosures in crops and exports. No customer relationship, delivered result or endorsement is claimed.
