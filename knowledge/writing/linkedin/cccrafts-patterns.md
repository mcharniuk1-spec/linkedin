# OutSpoken execution patterns from the CCCrafts review

This is owned workflow guidance for review, not a new activated skill or client application.

1. Keep each author’s source material, approved voice examples and revisions separate. A reviewer edit proposes a voice change. It does not silently overwrite the guide.
2. Plan each topic around a buyer question, source, author position, example and useful next action.
3. Keep company/person fit, observed interaction, confirmed need and expressed buying interest in separate fields. An engagement event is not a sales-stage transition.
4. A contact brief contains the verified context, actual reply, relevant resource, unanswered question, owner and agreed next step.
5. The publication record binds exact caption/media revision, target account, reviewer decision, schedule and actual published URL/status. Detect duplicates and retain failure states.
6. A weekly review names the observation and next decision. Distribution, conversations, meetings and revenue remain distinct measures.
7. Client handoff includes editable materials, source/rights limits, exports, owner, operating instructions and fallback.
8. A publishing vendor is an interchangeable adapter. Research permissions, author judgment and client account authority remain separate. Test the exact media format, target, metrics and exit route before adoption.

Apply through the existing founder-content-writing preparation, project reference-pattern review and publication-architecture skills, fact-preserving humanization and brand-system-delivery. No installed skill bundle was changed by this review.
