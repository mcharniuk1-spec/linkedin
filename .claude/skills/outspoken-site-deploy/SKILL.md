# Outspoken site: build, deploy, verify

1. **Build and check** in `design and website/website`: `npm ci --ignore-scripts && npm run typecheck && npm run build`. Run the repository verifiers (`python3 scripts/verify_release.py`, `node "design and website/scripts/verify-package.mjs"`, `python3 scripts/public_safety_scan.py`) before any push.
2. **Vercel connector, personal (hobby) scope:** the account is a personal one. **Do not pass `teamId` or `slug`** to any tool; passing the personal scope id returns 403 even though the connection is authorised, and an empty team list is normal. Find the project by name `outspoken-voice-7c4e2` with `list_projects` (no team parameter). Never ask for tokens or passwords.
3. **Deploy:** `create_deployment` needs file contents inline, so a 1 MB bundle cannot be uploaded directly. Use the build-from-commit recipe in `design and website/deploy/vercel/` (`vercel.json` + `scripts/vercel-build.sh` inline; set the commit SHA inside the script; already-uploaded media referenced by SHA-1). Target `production`, project by id, no `projectSettings` change. A failed build never moves the production alias; keep the previous deployment id for rollback. **Do not** use `create_deployment` with `deploymentId` plus a `files` override to "redeploy with one changed file": on 31 Oct 2026 that produced an empty READY deployment that took production to 404 for about two minutes. Always send the full file list. If production ever returns 404, call `request_promote` with the previous good deployment id and re-check the URL at once.
4. **Verify anonymously (required before saying "deployed"):** deployment state READY and alias set; fetch the public URL without credentials; every route returns 200; the HTML references the new `index-*.js/css`; compare the SHA-256 of every shipped file against the expected list (a missing path returns 200 with `index.html` because of the SPA rewrite, so a status code proves nothing: hash the body, and derive the expected set from the files the live HTML, JS and CSS reference plus `assets/identity/v10/**`); fonts and founder photos load; no console errors; no `citron` in the DOM; no horizontal overflow at 390 px.
5. **Record** the deployment id, previous id, commit, checks and gaps in `design and website/HANDOFF.md` and `deploy/vercel/README.md` (latest verified: commit `acf8655`, `dpl_Hx1irxvPivqP2n9hqMRZb2meRiCo`). Eleven rights-excluded media files are carried by SHA reference, not by the repository: do not drop them silently.
