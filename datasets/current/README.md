# Current public derived dataset

The checked public projection contains reference-publication identities/locators, original content interpretations, public observed counters/snapshots, compact original media analysis, transcript availability/QA state and company-level prospect summaries. The full local evidence store has the original post text, media and transcripts; those bytes are not distributed here.

Open [index.html](index.html) via a local static server. The reference and target-company views remain separate. Use [STATE.json](STATE.json), [gaps.json](gaps.json), [provenance.json](provenance.json), [dataset.json](dataset.json), [qualification-table.csv](qualification-table.csv) and [derived.sqlite](derived.sqlite). Publication date, capture time, descriptive performance and trend status are separate fields. Unknown counters remain unknown.

A source hash is an identity/provenance reference to local evidence, not a public content download or independent fact verification. A transcript availability label does not imply that a listener has verified audio accuracy. Media descriptions retain scope and claim/rights limitations. No recurring schedule is active.

[Company source index](company-sources.json) resolves the company-level evidence IDs to public locators and dated receipt hashes. Missing source references, if any, remain explicit.
